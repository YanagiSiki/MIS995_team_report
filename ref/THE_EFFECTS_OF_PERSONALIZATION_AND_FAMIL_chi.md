# 個人化與熟悉度對推薦代理程式信任與採納意願的影響

**作者**：Sherrie Y. X. Komiak（紐芬蘭紀念大學）、Izak Benbasat（英屬哥倫比亞大學）
**出處**：MIS Quarterly, Vol. 30, No. 4, December 2006

---

## 摘要

本研究以信任為核心，結合認知與情感雙重視角，探討電子商務情境中網路推薦代理程式（Recommendation Agent, RA）的採納行為。研究奠基於**理性行動理論（TRA）**、IT採納文獻及信任文獻，實證檢驗「感知個人化」與「熟悉度」對認知信任、情感信任的影響，以及這兩種信任如何影響使用者將RA採納為「決策輔助工具」或「委託代理人」的意願。

主要發現：

- 感知個人化顯著提升認知信任與情感信任，進而提高採納意願
- 情感信任在認知信任與採納意願之間扮演重要中介角色
- 熟悉度同樣透過認知信任與情感信任提升採納意願

---

## 一、緒論

### 1.1 研究背景

- **推薦代理程式（RA）**：依據使用者個人需求提供產品建議的個人化網路代理程式（如 ActiveBuyersGuide.com）
- RA 屬於個人化科技，能幫助使用者克服資訊超載、改善購買決策
- RA 廣泛採用是廠商與消費者獲益的前提，因此探討「為何及如何」促使消費者採納RA 是研究核心

### 1.2 研究缺口

- 現有 IT 採納理論（如 TAM、UTAUT）主要以認知為導向，未充分納入情感因素
- 個人化科技情境下，消費者同時扮演 IT 使用者與顧客雙重角色，情感因素不可忽視
- 既有信任研究多聚焦於認知信任，缺乏情感信任的實證探討

### 1.3 研究目的

採用以信任為核心的認知—情感平衡視角，探討個人化與熟悉度如何透過認知信任和情感信任，影響消費者採納RA的意願。

---

## 二、理論基礎與研究模型

### 2.1 理性行動理論（Theory of Reasoned Action, TRA）

- **核心邏輯**：行為意圖由「行為態度」決定（subjective norms 在自願使用情境下較不顯著）
- 本研究以信任為焦點，以認知信任（beliefs）替代一般認知信念，以情感信任（attitude）替代一般態度

### 2.2 認知信任（Cognitive Trust）

- **定義**：信任者對被信任者具備可依賴所需屬性的理性預期
- 來源於社會學、經濟學及政治學的理性選擇觀點
- 本研究將認知信任區分為：
  - **能力認知信任（CTC）**：顧客對 RA 具備提供優質建議能力的理性預期
  - **誠信認知信任（CTI）**：顧客對 RA 將提供客觀、不偏頗建議的理性預期

### 2.3 情感信任（Emotional Trust）

- **定義**：信任者對依賴被信任者所感受到的安全感與舒適感
- 根植於社會學、心理學與行銷學，包含直覺感受、信念，以及對情感反應的評估
- 情感信任 ≠ 基於情感的信任（affect-based trust）：前者關注信任者的感受，後者關注被信任者的情感

## 三、研究模型與假說

### 3.1 研究模型架構

```
感知個人化（PP） ─→ 能力認知信任（CTC） ─→ 情感信任（ET） ─→ 採納為決策輔助（IAid）
                                               ↗             ↘
感知個人化（PP） ─→ 誠信認知信任（CTI） ─→                  → 採納為委託代理（IDeleg）
熟悉度（F）     ─→ 能力認知信任（CTC）
熟悉度（F）     ─→ 誠信認知信任（CTI）
```

### 3.2 假說彙整

| 假說 | 內容                                   |
| ---- | -------------------------------------- |
| H1   | 感知個人化正向影響對 RA 能力的認知信任 |
| H2   | 感知個人化正向影響對 RA 誠信的認知信任 |
| H3   | 熟悉度正向影響對 RA 能力的認知信任     |
| H4   | 熟悉度正向影響對 RA 誠信的認知信任     |
| H5   | 能力認知信任正向影響情感信任           |
| H6   | 誠信認知信任正向影響情感信任           |
| H7   | 情感信任正向影響採納RA為決策輔助的意願 |
| H8   | 情感信任正向影響採納RA為委託代理的意願 |

### 3.3 兩種採納意願的區別

- **決策輔助（Decision Aid）**：顧客依據 RA 建議進行篩選，最終仍自行決策（較低依賴度）
- **委託代理（Delegated Agent）**：顧客直接接受 RA 決定，不逐一審查建議（較高依賴度）

## 四、研究方法

### 4.1 研究設計

- **2×2 因子實驗設計**：個人化（低/高）× 熟悉度（低/高），共四組
- 使用同一商業網站（activebuyerguide.com）的兩款 RA

### 4.2 自變數操弄

**感知個人化（PP）**：

- 高個人化 RA：提供需求導向問題（need-based questions）、屬性相對重要性設定
- 低個人化 RA：直接讓使用者指定各屬性偏好，無需求引導
- 操弄確認：高個人化組 M = 5.5 vs. 低個人化組 M = 4.4，F = 26.0, p < 0.001

**熟悉度（F）**：

- 低熟悉度組：僅使用 RA 購物一次（筆電）
- 高熟悉度組：使用 RA 購物三次（筆電、桌機、數位相機）
- 操弄確認：高熟悉度組 M = 5.5 vs. 低熟悉度組 M = 4.6，F = 5.4, p < 0.01

### 4.3 依變數測量

所有量表為 7 點 Likert 量表，來自三階段量表開發程序（量表創建→排序測試→因素分析），主要構念包含：

| 構念                         | 題項數 |
| ---------------------------- | ------ |
| 感知個人化（PP）             | 3 題   |
| 熟悉度（F）                  | 1 題   |
| 能力認知信任（CTC）          | 2 題   |
| 誠信認知信任（CTI）          | 3 題   |
| 情感信任（ET）               | 3 題   |
| 採納為委託代理意願（IDeleg） | 2 題   |
| 採納為決策輔助意願（IAid）   | 3 題   |

### 4.4 研究參與者

- 100 名北美商學院學生（2002年資料收集）
- 篩選條件：曾有網路購物經驗，且對實驗產品有購買意願
- 隨機分配至四組；各組在網購經驗上無顯著差異
- 實驗時間約 75–100 分鐘

## 五、資料分析與結果

### 5.1 分析方法

- 使用 **PLS（偏最小平方法，PLS-Graph 3.00）** 進行結構方程模型分析
- 選擇 PLS 而非 LISREL，因本研究屬探索性研究（theory development）

### 5.2 測量模型

**收斂效度**：

- 各題項因素負荷量均 > 0.70（符合 Barclay 等人 1995 建議）
- 組合信度（CR）介於 0.89–0.95，均 > 0.70
- 平均變異抽取量（AVE）介於 0.79–0.89，均 > 0.50

**區別效度**：

- 因素分析顯示各題項負荷在對應構念上
- 各構念 AVE 平方根均大於其與其他構念之相關係數

### 5.3 結構模型（假說驗證結果）

所有假說均獲得支持（模型 R² 介於 25%–58%）：

| 路徑        | 標準化路徑係數 (β) | 顯著性   |
| ----------- | ------------------ | -------- |
| PP → CTC    | 0.44               | p < 0.01 |
| PP → CTI    | 0.43               | p < 0.01 |
| F → CTC     | 0.12               | p < 0.05 |
| F → CTI     | 0.21               | p < 0.05 |
| CTC → ET    | 0.52               | p < 0.01 |
| CTI → ET    | 0.37               | p < 0.01 |
| ET → IAid   | 0.72               | p < 0.01 |
| ET → IDeleg | 0.72               | p < 0.01 |

### 5.4 中介效果分析

| 中介關係              | 結果                                |
| --------------------- | ----------------------------------- |
| CTC、CTI 中介 PP → ET | **部分中介**（PP 直接影響 ET）      |
| CTI 中介 F → ET       | **完全中介**                        |
| ET 中介 CTC → IAid    | **完全中介**                        |
| ET 中介 CTI → IAid    | **部分中介**（CTI 仍直接影響 IAid） |
| ET 中介 CTC → IDeleg  | **完全中介**                        |
| ET 中介 CTI → IDeleg  | **完全中介**                        |

## 六、討論與結論

### 6.1 認知信任與情感信任在 IT 採納中的角色

- 認知信任（能力與誠信）顯著正向影響情感信任，與 TRA 的信念→態度預測一致
- 情感信任在採納意願中具有超越認知信任的獨立貢獻
- 對於「委託代理」採納，情感信任完全中介認知信任的效果；對「決策輔助」採納，則為部分中介

### 6.2 個人化與熟悉度的角色

- **感知個人化**：主要驅動力，透過提高認知信任與情感信任，顯著提升採納意願
- **熟悉度**：同樣正向影響認知信任與情感信任，但效果相對較小

### 6.3 理論貢獻

1. 拓展 IT 採納理論，將情感因素（情感信任）納入採納模型
2. 區辨認知信任與情感信任，並實證其間的關係
3. 區辨兩種採納意願（決策輔助 vs. 委託代理），提供更細緻的採納行為分析

### 6.4 實務意涵

- 電子商務廠商應提升 RA 的個人化程度（如引導式需求問題、屬性權重設定），以增強顧客信任
- 鼓勵重複使用 RA，積累熟悉度，可同步強化認知信任與情感信任
- 情感信任的提升有助於促使顧客將 RA 作為委託代理人，提高決策效率
